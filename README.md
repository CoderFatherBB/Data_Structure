## About

This repository contains focused C implementations of common data structures and algorithms. Each source file is a standalone practice example for a specific concept.

## Included Topics

- Stack examples: parentheses matching, palindrome checking, postfix conversion/evaluation.
- Linked lists: singly and doubly linked list implementations.
- Trees: binary search tree, threaded BST, min heap.
- Graphs and algorithms: adjacency list creation and Dijkstra's algorithm.
- Queue and Josephus problem variants.


## Getting Started

Clone the repository:

```bash
git clone https://github.com/CoderFatherBB/Data_Structure.git
cd Data_Structure
```

Open the folder or notebook you want to explore. Most directories are self-contained, so start from the local `README.md`, source file, notebook, or project folder for that topic.
